# Demo video script: Store Coach (max 2:00)

**Record:** Loom, screen + voice, browser full screen at https://store-coach-mu.vercel.app
**Before recording:** open the link in a fresh window → sidebar bottom → **Reset demo updates**. Role = Area Manager, Rakesh Srivastava · Lucknow. Zoom the browser to 90%.
**Upload:** Loom link set to "Anyone with the link can view". Open it in an incognito window to check before submitting.

| Time | On screen (do this) | Say this |
|---|---|---|
| **0:00–0:12** | Area Overview: KPI cards and store health grid | "This is Store Coach. Every morning, without anyone asking, it tells each Manyavar area manager which stores need attention and why, and gives every salesperson one thing to do better today. It opens without a login." |
| **0:12–0:30** | Point at the red **LKO-02** tile, then scroll to **Most important issues** | "Rakesh runs four Lucknow stores. One is critical. Each alert names the lever, the evidence, one action, the owner, and confidence." |
| **0:30–0:42** | Sidebar → **AI Insights** → scroll past discount (Manoj N. 4.7% vs 1.8%) and repeat (Kunal C. 0 of 235) | "It looks through all three levers: more bills, bigger baskets, more repeat. It compares each store with its own season last year, so Diwali doesn't cause false alarms, and salespeople only with peers in their own store." |
| **0:42–0:55** | Click **+ Create follow-up** on the Imran alert → form is pre-filled → **Assign follow-up** | "One click turns an alert into a tracked follow-up. Evidence, action and the before-metric are filled in, and duplicates are blocked." |
| **0:55–1:15** | Top-left **view as → Store Manager → LKO-02** → **My Tasks** → open FU-001 → **Start work** → type remark → attach a photo → **Submit as done** | "Now the store manager. | **1:30–1:42** | **view as → Salesperson** → coaching card → **Got it!** | "Each salesperson gets a card of under 60 words: one behaviour, a better peer from the same store, and one action for today." |
| **1:42–1:52** | **Area Manager → Data Issues** (PAT-03 camera) then **Visit Planner** | "Numbers that can't be right, like a door camera reading zero for 12 days while the store was selling, are flagged and kept out of alerts. The visit planner tells Rakesh which stores are worth a trip." |
| **1:52–2:00** | **Impact & Reports** → point at the CSV buttons | "It runs on its own every morning on the full Manyavar data pack, and every headline number is independently spot-checked. Store Coach: more bills, bigger baskets, more repeat." |

**Tips**
- Practise once, then record in one take. If you go over 2:00, cut the 1:42–1:52 section.
- Keep the mouse still while you talk; move it only to click.
- Do the follow-up flow in **one browser window**. Updates are saved in that browser.
