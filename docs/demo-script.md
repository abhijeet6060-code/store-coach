# Demo video script: Store Coach (max 2:00)

**Record:** Loom, screen + voice, browser full screen at https://store-coach-mu.vercel.app
**Before recording:** open the link in a fresh window → enter as any role → sidebar bottom → **Reset demo updates** → **⇄ Switch role** back to the welcome screen. Zoom the browser to 90%.
**Upload:** Loom link set to "Anyone with the link can view". Open it in an incognito window to check before submitting.

It runs every morning on the full data, and the headline numbers are independently spot-checked. Store Coach: more bills, bigger baskets, more repeat." |

**Tips**
- Practise once, then record in one take. If you go over 2:00, cut the 1:30–1:40 Stores section.
- Keep the mouse still while you talk; move it only to click.
- Do the whole flow in **one browser window**. Follow-ups and remarks are saved in that browser.
- Made a wrong follow-up while practising? Open it as Area Manager → **Delete**.
- On a phone, the orange **AI** button in the header runs the same analysis.
